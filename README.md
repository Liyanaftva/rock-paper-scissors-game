## Features

- **Classic gameplay** — pick Rock, Paper, or Scissors and play against the computer
- **Animated countdown** — a 3-2-1 countdown with both hands "shaking" before the reveal, mimicking how the game is played in real life
- **Auto-reset** — hands and result reset automatically after each round, ready for the next play
- **Running score tracker** — keeps count of player vs. computer wins across rounds
- **Editorial-style design** — serif typography, muted gold accents, hairline borders, and a layered card layout for a refined, minimalist aesthetic
- **Micro-interactions** — sweep-in hover effect on buttons, staggered entrance animations, and smooth fade transitions on results
- **Fully responsive** — adapts to mobile and smaller screens

## Tech Stack

- HTML
- CSS (vanilla, no frameworks — custom animations, layered shadows, pseudo-element detailing)
- JavaScript (vanilla, no libraries)

## How to Play

1. Click **Rock**, **Paper**, or **Scissors**
2. Watch the countdown as both hands "shake"
3. See the result — win, lose, or draw — and watch your score update
4. Hands reset automatically, ready for the next round

## Running Locally

No build step or dependencies required. Just clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/Liyanaftva/rock-paper-scissors-game.git
cd rock-paper-scissors-game
```

Then open `index.html` directly, or use a live server extension for auto-reload while editing.
